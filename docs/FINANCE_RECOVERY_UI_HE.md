# גרסאות, השוואה ושחזור אשראי

בשני האתרים: אשראי ← פתיחת הגדרות הסנכרון ← **גרסאות וגיבוי אשראי**.
המסך נטען רק בעת הפתיחה, עבור החשבון הפעיל ובתנאי שהגישה הפיננסית מותרת.

1. בוחרים גרסה; מוצגת השוואה לראש Finance שנקרא כעת מהענן.
2. משווים כרטיסים, חודשים, ספירות וסכומים שקליים, כולל פירוט התנועות
   שייגרעו/יתווספו. סכום כולל זהה אינו מסתיר החלפת עסקאות. סכומי חוץ
   שאינם חיוב שקלי מסומנים ואינם מומרים לפי שער משוער. ריבוי נשמר.
3. אפשר לייצא את הגרסה לקובץ JSON עצמאי. השרת מחזיר את הטקסט המקורי
   שנחתם ב־SHA-256 והדפדפן מאמת אותו לפני יצירת הקובץ. הקובץ מכיל Finance
   מלא, כולל בנק; אין בו סיסמאות Bridge. יש לשמור אותו ביעד עצמאי מוגן.
4. שחזור דורש סימון שנבדקה ההשוואה, סיבה של 8–500 תווים ואישור מפורש.
   הלקוח מקבל נעילת אשראי עם heartbeat, קורא שוב את הראש ודוחה שינוי
   ב־revision מאז התצוגה. הוא שולח מזהה גרסה בלבד, ללא נתוני החלפה חופשיים.
5. השרת משחזר **creditSync בלבד** ומשאיר את הבנק העדכני. התשובה נבדקת
   כאישור כתיבה, ואחריה נקרא הראש שוב ונבדק האשראי. כשל בתצוגה הנלווית
   אינו יוצר שחזור אוטומטי חוזר. ב־ACK אבוד יש לקרוא ולהשוות שוב לפני פעולה.

מיגרציה נדרשת: `20261115200000_finance_version_export.sql`, אחרי מיגרציית
ההמשך `20261115183000_credit_reconciliation_followup.sql`. לא שוכתבו גרסאות
SQL קיימות ולא בוצעה פריסה לייצור במסגרת שלב הקוד. API הגרסאות נשאר מוגבל
לבעלים עם מדיניות MFA. אין כאן ייבוא קובץ חופשי לתוך נתוני הייצור.

## ניסוי שחזור עצמאי

לאחר ייצוא גרסה ניתן להריץ בסביבת פיתוח עם PostgreSQL מותקן:

```powershell
python tools/finance_backup_drill.py --backup "C:\Backups\finance-backup-2.json"
```

הכלי אינו מקבל URL או פרטי מסד. הוא מאמת checksum, מקים PostgreSQL מקומי
מבודד, משחזר את הקובץ, מחיל את שרשרת המיגרציות ומשווה את **כל מצב Finance**
ששוחזר למקור הקובץ. בסיום המסד הזמני מוסר. פלט התוצאה מכיל סטטוס וספירות
בלבד. `tests/finance_history_backup_server.py` מבצע ייצוא UTF-8 דרך RPC אמיתי,
סוגר את מסד המקור ומשחזר את הקובץ למסד מבודד אחר; הוא גם מוכיח דחיית שינוי
בקובץ ובידוד בעלים. בדיקות MFA כוללות גם את ממשק הייצוא החדש.

קובץ נבדק אינו שירות גיבוי אוטומטי או PITR. המשתמש בחר בשלב זה בייצוא לקובץ;
ניסוי על נתונים סינתטיים אינו טענה שבוצע שחזור של קובץ הייצור שלו.

## הכרעה בחיובים ידניים ישנים

החיובים נשארים כלולים כל עוד לא הוכחה החלפה. במצב מעורב מופיעה הודעת
השוואה. עריכת חיוב ידני כוללת בחירת ארכיון מפורשת וסיבה לשינוי; רשומה
הדורשת בדיקת מקור מחייבת סימון שההשוואה נעשתה. ארכוב מוציא מהחישוב אך
משאיר את המזהה, נתוני המקור והרשומה בגיבוי. ניתן לפתוח גם רשומות בארכיון
ולבטל את הארכוב עם סיבה. אין התאמה אוטומטית לפי סכום או סיומת כרטיס.
