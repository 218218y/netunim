# תשובות MAX וכיסוי תחזית — Bridge 87

באבחון Bridge 86 נשמר מבנה של תשובות שפוענחו בהצלחה בלבד. לכן לא היה
אפשר להכריע מה התקבל עבור חודשי 2027 שנדחו. במקביל, בקשת HTTP לחודש
תחזית בוצעה מחוץ לטיפול בשגיאת החודש: שחזור של HTTP 503 ביטל הצלחת
ליבה שכבר נקראה. אלה שני הפערים המאומתים שמטופלים בשלב זה.

## הכללים

- Fetch, פענוח ונרמול מתבצעים כיחידה חודשית. תנועות נכנסות לתוצאה רק
  לאחר אימות כל תנועות החודש בזיכרון זמני.
- שגיאות מבנה, JSON, רשת, HTTP 408 או HTTP 5xx בחודש תחזית אופציונלי
  מסמנות כיסוי כושל ואזהרה בלי לבטל את חודשי הליבה. `fetchedAt` בחודש
  הכושל נשאר null; מנגנוני המיזוג שומרים את הנתונים הקודמים כלא מעודכנים.
- כשל בחודש ליבה, 401, 403, 429, חסימת אוטומציה או חריג לא מוכר עדיין
  מפסיקים את הפרופיל. אין עקיפת חסימה, retry או איפוס נתונים.
- `result.transactions=[]` מזוהה ממשיך להוכיח חודש ריק. `result:null`,
  מעטפת חסרה, גוף ריק או JSON לא תקין אינם מוכיחים היעדר תנועות.
- אין קביעה של אופק זמינות MAX או של תשובת empty חלופית ללא ראיה חדשה.
  מדיניות השימור, מנוע החיובים, SQL ומצב recovery אינם משתנים.

## אבחון 4

כל חודש, כולל חודש שנדחה וכשל ליבה, מקבל רשומת `providerEvidence`.
השדה `response` כולל חודש ו-tier, endpoint קבוע, HTTP status אמיתי,
סיווג MIME וגוף, טיפוס המעטפת ו-result, טיפוס/כמות transactions,
מסלולי מערכים ומפתחות מדגם, סיבת דחייה והכרעה מבנית.
ההכרעות הן `verified_rows`, `verified_empty`, `unrecognized_schema`,
`transport_failure`. מצב unsupported אינו מומצא מתוך תשובה חסרה.

הראיות החדשות מכילות טיפוסים, שמות שדות, כמויות ודגלי boolean מוגדרים;
אין בהן גוף תגובה, ערכי שדות עסקאות, כתובות בקשה, cookies או סודות.
אוסף המבנה מוגבל בעומק, במספר הצמתים והמערכים, ונבדק שוב בזמן ייצוא.
דוגמאות תנועה מקומיות קיימות נשארות מסומנות בקובץ כאבחון הכולל דוגמאות.
כשל בשמירת האבחון אינו משנה את תוצאת הסנכרון הפיננסי.

## מקור והשער הבא

נבדק גם [מימוש MAX המקורי](https://github.com/eshaham/israeli-bank-scrapers/blob/master/src/scrapers/max.ts).
הוא משתמש באותו `YYYY-M-01` ומחזיר אוסף ריק כש-result חסר. אין בכך
הוכחה מספקת לדריסת חודש שמור, ולכן התנהגות זו אינה מועתקת למערכת.

לאחר התקנת Bridge 87 דרושה ריצה מאומתת אחת וייצוא אבחון 4. יש להשוות
חודש בקרה מוצלח (דצמבר 2026), ינואר 2027 וחודש רחוק נוסף. רק לאחר
קבלת המבנים ניתן להוסיף fixture ולהחליט אם נתמכת תשובת empty חלופית
או אם קיימת מגבלת זמינות מפורשת. עד אז הכיסוי החסר נשאר גלוי.
