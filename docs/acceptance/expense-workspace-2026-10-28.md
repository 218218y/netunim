# Expense intake workspace

The intake surface uses a restrained pale background and two titled panels: white expense fields and a lightly tinted source document panel. Borders, spacing and a subtle shadow distinguish the areas without changing form order. The empty PDF/file target now occupies useful viewport space, supports the existing drag/paste/native file-picker routes and has a labeled keyboard-accessible input. After selection it contracts so the PDF preview retains its existing generous viewport.

The desktop columns stack on narrow screens with a smaller empty target. Real-browser geometry checks cover both widths, empty/selected states, visible separation, keyboard access and absence of horizontal overflow. Existing paired-control geometry, recognition, queue, source recovery and financial-flow coverage remains in full CI. Complete Orders frontend assets and regenerated cache headers must ship together.
