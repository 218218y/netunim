# שימוש בניהול קופה

הפעילו את [קובץ Kupa](../../.02%E2%80%8F%E2%80%8Frun%20kupa.bat) לפיתוח מקומי, או פתחו את [אתר הקופה](https://kupa.bargig-furniture.com/) לעבודה רגילה. לפני סגירה או מעבר למחשב אחר, בדקו את סטטוס השמירה והסנכרון.

- התקינו את [Bank Bridge](connectors.md) בכל מחשב שמרענן בנק או אשראי. הגדירו חיבור דרך האפליקציה ובחרו בחשבון הרצוי. במחשב נוסף השתמשו ב־**הגדר גם במחשב זה** בפרופיל האשראי הקיים, כדי לשמר את המזהה והיסטוריית השיוך.
- שימו לב לאיזה חשבון שייכת היתרה, אם מקור הנתונים ידני או מסונכרן, ואילו תקופות חסרות כיסוי. בחירת תאריך בתחזית משנה את אופק החישוב. ראו [כללי תזרים](../../shared/cashflow.md).
- צ׳קים משותפים עם Orders. תנועה חלקית מהבנק אינה מסיימת התאמה. בדקו מקרה עמום מול מקור הבנק ופרטי הצ׳ק.
- לפני איפוס או טעינת גיבוי בדקו את [מדריך ההתאוששות](recovery.md). כדי לבדוק שינוי באשראי השתמשו בהשוואת הגרסאות במקום לשנות נתוני בנק או לאפס נתוני דפדפן.
