# שימוש בניהול הזמנות

הפעילו את [קובץ Orders](../../.01run%20orders.bat) לפיתוח מקומי, או פתחו את [אתר ההזמנות](https://orders.bargig-furniture.com/) לעבודה רגילה. אפשר להשתמש במעטפת האפליקציה גם במצב לא מקוון. לפני סגירה או מעבר למחשב אחר, בדקו את סטטוס השמירה והסנכרון.

- השתמשו בבורר התיקיות דרך האפליקציה והעניקו הרשאה רק ליעד העבודה או הגיבוי המיועד. אם הרשאת הדפדפן פגה, בחרו את התיקייה שוב דרך הפעולה הרגילה.
- לחיפוש מקומי ב־Windows ראו [מחבר המסמכים](connectors.md) ו־[התנהגות החיפוש והתצוגה](../integrations/document-search.md). לחיפוש בקובצי Drive או לחיבור יומן ראו [Google](../integrations/google.md).
- להפקה מחוב או מתנועת בנק ולצפייה בדוחות ראו [הכנסות ב־Morning](../integrations/morning-income.md). לקליטת ספקים וחשבוניות ראו [הוצאות ב־Morning](../integrations/morning-expenses.md).
- לגיבוי, שחזור או סנכרון שממתין לבדיקה, השתמשו ב־[מדריך ההתאוששות](recovery.md).
