# שדרוג הגליונות — הרצה בענן

להריץ ב־PowerShell מתוך תיקיית `netunim`. אם ה־CLI אינו מחובר לחשבון, להריץ קודם `supabase login`.

```powershell
supabase db push --linked --project-ref bupoidcurcxuypfrjqio --dry-run --skip-vault
supabase db push --linked --project-ref bupoidcurcxuypfrjqio --skip-vault
python tools/supabase_deploy_gate.py
.\deploy_all.bat
```

יש להתקדם לפקודה הבאה רק לאחר הצלחת הקודמת. `deploy_all.bat` מריץ את כל הבדיקות ומפרסם את שתי המערכות. לאחר הפרסום יש לרענן את שני האתרים.

הבדיקה המקדימה מול הענן ב־17.9.2026 מצאה שני עדכונים ממתינים:

- `20260917150000_orders_notes_workbook.sql`
- `20260917180000_independent_spreadsheet_documents.sql`

אין להריץ SQL ידנית או להשתמש ב־`migration repair`: ה־CLI ישמור את סדר העדכונים ואת היסטוריית ההרצה. העדכון מעתיק ומאמת את הגליונות לפני הסרת העותק מהמסמך הראשי, ושומר עותק מקור וגיבוי מעבר. נתונים לא תקינים עוצרים את העסקה כולה.

## התנהגות לאחר העדכון

- לכל מערכת מסמך גליון עצמאי עם הרשאות בעלים, גרסה וגיבויים משלו. עריכת גליון אינה שומרת מחדש ספקים, לקוחות או תנועות קופה.
- הערות רגילות הן ברירת המחדל בהזמנות. הגליון נטען בפתיחת לשונית הגליון.
- טיוטות תאים נשמרות ב־IndexedDB בחלונות של 120 אלפיות השנייה; שמירת ענן מאוחדת מתבצעת לאחר 1.8 שניות ללא עריכה. שינוי מבני או מחיקה נשמרים מיד.
- גיבויי עריכות רגילות מאוחדים לחלונות של 10 דקות. מחיקה ושחזור מקבלים גיבוי בטיחות נפרד. עד 100 גיבויים רגילים, עד 30 יום; גיבוי המעבר נשמר בנפרד.
- גיבוי, ייצוא, ייבוא ושחזור הגליונות נמצאים בסרגל הגליון. שחזור נתוני המערכת הראשיים אינו משחזר את הגליונות העצמאיים.
- מעל 200 שורות מוצגים מקטעים של 100 שורות. הסכומים כוללים את כל השורות; ניווט במקלדת עובר גם בין המקטעים.
- שתי עריכות בתאים שונים מתמזגות. שינוי סותר באותו תא או מחיקה במקביל לעריכה עוצרים את השמירה ומאפשרים הורדת עותק מקומי לפני טעינת הענן.

## בדיקות

בדיקות ייעודיות: `tests/spreadsheet_sync.test.mjs`, `tests/spreadsheet_documents.py`, `tests/spreadsheet_runtime.py` ובדיקות העבודה בדפדפן של שתי המערכות. כולן כלולות ב־`python tests/run_all.py`.

במדידה מקומית עם 5,000 שורות ו־5 עמודות, התצוגה צומצמה מ־25,000 ל־500 תאים וזמן התצוגה ירד מכ־3.02 שניות לכ־0.26 שניות. הזמנים תלויים במחשב. תרחיש של 100 עריכות רצופות נבדק עם קריאת שמירת ענן אחת. נבדקו גם שחזור טיוטה ללא blur, רשת מנותקת, תשובה שאבדה, החלפת חשבון, מחיקה מול עריכה מרוחקת ושחזור גליון ללא שינוי בגרסאות המסמכים הראשיים.
