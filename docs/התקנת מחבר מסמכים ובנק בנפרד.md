# הצמדת המחברים של Netunim בתחנת הפיילוט

תחנת הפיילוט מוכנה. Document Bridge 48 ו־Bank Bridge 79 במצב `scoped`, עם שלוש הצמדות פעילות בכל מחבר. בדיקת קריאה מקומית אישרה ששני המחברים דוחים את המפתח הישן. שמור את `bridge-token.txt` בתיקיית המחבר לשימוש לפי נוהל השחזור.

שלבים 1–5 מסבירים איך לבצע הצמדה חוזרת בפיילוט אם יהיה צורך. להקמת מחשב נוסף, עבור לסעיף **שני המחשבים הנוספים**.

## 1. פותחים את המסוף ואת האתר

- השתמש בחלון PowerShell של הפיילוט שכבר פתוח. אם הוא ממתין לקוד של `DocProof`, לחץ Ctrl+C פעם אחת כדי לחזור לשורת `PS ...>`.
- אם החלון נסגר, פתח PowerShell 7 והרץ את השורה הבאה פעם אחת.

```powershell
. 'C:\Users\יעקב\Downloads\pro\netunim\.work\netunim-pilot-pairing-console.ps1'
```

- פתח את דף האבטחה בדפדפן ובפרופיל שבהם אתה עובד עם האתר. בחיבור המקומי הפעל תחילה את האתר המקומי בדרך הרגילה וודא ששורת הכתובת מתחילה בדיוק ב־`http://localhost:3000`.

## 2. מצמידים את אתר ההזמנות

פתח [אבטחת אתר ההזמנות](https://orders.bargig-furniture.com/security.html).

1. במסוף הרץ `DocIssue https://orders.bargig-furniture.com` ולחץ Enter.
2. כשהמסוף מציג `Type APPROVE to continue:`, הקלד `APPROVE` ולחץ Enter.
3. בדף האבטחה, בסעיף **הצמדת מחבר למחשב הזה**, בחר **Document Bridge**. העתק רק את הקוד שמתחיל ב־`ntp1.` לשדה **קוד הצמדה חד־פעמי**, ולחץ **הצמד לאתר הזה**. הקוד תקף לשתי דקות. הודעת הצלחה אומרת **המחבר הוצמד לאתר הזה**.
4. רק אחרי ההצלחה, הרץ `BankIssue https://orders.bargig-furniture.com`. הקלד `APPROVE` כשהמסוף מבקש. באותו דף בחר **Bank Bridge**, הדבק את הקוד החדש ולחץ **הצמד לאתר הזה**.

## 3. מצמידים את אתר הקופה

פתח [אבטחת אתר הקופה](https://kupa.bargig-furniture.com/security.html) וחזור על אותו סדר.

1. למחבר המסמכים הרץ `DocIssue https://kupa.bargig-furniture.com`. אשר במסוף ובחר **Document Bridge** בדף הקופה.
2. למחבר הבנק הרץ `BankIssue https://kupa.bargig-furniture.com`. אשר במסוף ובחר **Bank Bridge** בדף הקופה.

## 4. מצמידים את האתר המקומי

פתח [אבטחת האתר המקומי](http://localhost:3000/security.html) אחרי שהפעלת את האתר על פורט 3000.

1. למחבר המסמכים הרץ `DocIssue http://localhost:3000`. אשר במסוף ובחר **Document Bridge** בדף המקומי.
2. למחבר הבנק הרץ `BankIssue http://localhost:3000`. אשר במסוף ובחר **Bank Bridge** בדף המקומי.

כל קוד מתאים רק לכתובת ולמחבר שלשמם נוצר. צור קוד אחד בכל פעם, כשהדף הנכון כבר פתוח. אם הקוד פג או נדחה, בדוק את הכתובת בשורת הדפדפן ואת המחבר שנבחר והרץ מחדש את אותה פקודה. אם הדפדפן מבקש גישה לרשת המקומית, אשר אותה עבור האתר שאתה מצמיד. את הקוד מדביקים רק בדף המתאים. בשורת `PS ...>` מריצים פקודות, ואת `APPROVE` מקלידים רק כשהמסוף מבקש אותו.

## 5. בודקים לפני שסוגרים את הגישה הישנה

1. רענן את האתרים. בכל כתובת חפש מסמך מוכר ונסה לפתוח ולהציג אותו. בדוק גם PDF רגיל ואינטראקטיבי, Word ו־Excel.
2. מתוך האתר, בצע רענון רגיל של הבנק ושל האשראי ובדוק שהמידע התעדכן. אם יש תור או אימות ספק, השלם אותו דרך הממשק הרגיל. אפשר לבדוק הגדרות קיימות בלי לשנות פרטי חשבון או להסיר חיבור.
3. במסוף הרץ בנפרד `DocPair status` ו־`BankPair status`. בכל מחבר צריכות להופיע שלוש הכתובות שהצמדת, עם ההרשאות שאושרו לפיילוט.
4. אם המחבר עדיין במצב `transition` וכל הבדיקות עברו, הרץ את פקודת הסיום שלו, `DocPair finish` או `BankPair finish`, והקלד `APPROVE` כשהמסוף מבקש.
5. הרץ שוב את שתי פקודות `status`. ודא שהן מציגות `scoped`, ואז בדוק שוב חיפוש ותצוגה ואת מצב הבנק והאשראי.

במחשב שנמצא במצב `transition`, כתובת שטרם הוצמדה יכולה להמשיך לעבוד עם המפתח הישן עד `finish` או עד תום החפיפה. אפשר להפיק קודים חדשים גם במצב `scoped`.

## שני המחשבים הנוספים

1. עדכן את המאגר מ־`main` והפעל את שני המתקינים באותו מחשב. שמור את התיקיות וההגדרות המקומיות הקיימות.
2. פתח PowerShell במחשב שבו התקנת את המחברים והדבק את בלוק ההכנה הבא פעם אחת. הוא יוצר את אותן פקודות קצרות ששימשו בפיילוט. פקודות `DocIssue` ו־`BankIssue` מעניקות את ההרשאות שאישרת לפיילוט. אם במחשב מסוים דרושות פחות הרשאות, השתמש בפקודת `issue` עם רשימת ההרשאות הדרושה.

```powershell
$docRoot = Join-Path $env:LOCALAPPDATA 'NetunimDocumentBridge'
$bankRoot = Join-Path $env:LOCALAPPDATA 'NetunimKupaBankBridge'
$docNode = (Get-Content (Join-Path $docRoot 'node-runtime.txt') -TotalCount 1).Trim()
$bankNode = (Get-Content (Join-Path $bankRoot 'node-runtime.txt') -TotalCount 1).Trim()
$docApp = (Get-Content (Join-Path $docRoot 'active-runtime.txt') -TotalCount 1).Trim()
function DocPair { & (Join-Path $docRoot "$docNode/node.exe") (Join-Path $docRoot "$docApp/server.mjs") --pairing @args }
function BankPair { & (Join-Path $bankRoot "$bankNode/node.exe") (Join-Path $bankRoot 'app/server.mjs') --pairing @args }
function DocIssue([string]$origin) { DocPair issue $origin document.read document.delete document.maintenance }
function BankIssue([string]$origin) { BankPair issue $origin bank.read bank.refresh bank.configure bank.remove }
```
